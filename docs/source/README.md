# Hollowmere source bundle

This archive contains the 10 files supplied for the Hollowmere game build.

## Included files
- `build_printables.py`
- `test_rules_doc.py`
- `reference.html`
- `cards.html`
- `HOW_TO_PLAY.md`
- `snowball.py`
- `SYSTEMS_DESIGN.md`
- `config.py`
- `experiments_snowball.txt`
- `test_index.py`

The supplied files are preserved unchanged. They are a source/reference bundle, not a complete runnable repository: some Python modules referenced by the scripts (such as the `hollowmere_sim` package, `build_index.py`, and `graphics.py`) are not included in this archive.
